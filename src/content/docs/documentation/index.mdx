This is One Degree North's reference documentation, organized by subteam.
Where the [lessons](/lessons/) teach you a skill from scratch, these articles
are what you come back to later: build standards, tool setups, wiring
conventions, checklists, and season-to-season decisions worth remembering.
Use the search bar (top of the page) to find anything.

## For documentation authors

Anyone on the team can add an article — no coding required:

1. Open the [content editor](https://frc-website-zeta.vercel.app/keystatic)
   and sign in with GitHub. (You need to be in the team's **FRC Robotics**
   GitHub group — ask a team lead to add you.)
2. Pick your subteam's **Documentation** collection, click **Add**, and write
   your article. Headings, links, and code blocks are in the toolbar; images
   can be dragged straight into the editor.
3. Make the **slug** start with a number to control its order in the
   sidebar, like `03-wiring-standards` (the editor shows a hint for this).
4. Save. The site updates automatically within a couple of minutes.

Each subteam's overview article doubles as a formatting example — copy what
it does.
